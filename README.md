# 📘 React Teaching Guide for Students

Welcome to the **React Teaching Guide**! This folder contains example files and step-by-step instructions to help students understand and apply core React concepts, including:

- ✅ Creating reusable components  
- 🎯 Passing and using props  
- 🔁 Managing state with `useState`  
- ⏳ Working with side effects using `useEffect`
